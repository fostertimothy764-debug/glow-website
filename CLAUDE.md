# glow-website

Static demo site for "Glow by Gabby" — plain HTML/CSS/vanilla JS, no framework, no build step.

## Deployment

After completing a change, commit and push to `origin` on the current branch — do this
automatically, without asking for confirmation first. The user has standing-authorized this.

GitHub Pages is configured (legacy branch-based build) to serve directly from this branch's
root, so every push auto-deploys — no separate deploy step or CI workflow needed.

Live site: https://fostertimothy764-debug.github.io/glow-website/
